# Practical Deep Learning for Coders

Curriculum implementations, computer vision fine-tuning pipelines, and deep learning architectures built through the Fast.ai course practical notebooks.

## Modules

- Deep learning model training and inference with PyTorch and Fast.ai.
- Transfer learning on vision backbones (ResNet, ConvNeXt).
- Data augmentation pipelines, tabular deep learning, and metric calibration.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
pip install -r requirements.txt
```
